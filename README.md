# Camera Management Admin

Java Swing desktop admin app for editing camera management configuration files.

## Run

```bash
./run.sh
```

By default, the app edits:

- `/Users/hanna/IdeaProjects/camera-management-plugin/src/camera/configuration/files/cameras.yaml`
- `/Users/hanna/IdeaProjects/camera-management-plugin/src/camera/configuration/files/motion-detection.yaml`
